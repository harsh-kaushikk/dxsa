# Khalistan Football Association — Tri-fold Brochure

Professional landscape tri-fold brochure (11" × 8.5").

## Files

- `kfa-brochure.html` — print-ready source
- `KFA_Brochure.pdf` — generated PDF
- `generate_pdf.sh` — regenerates the PDF with Chrome

## Front cover note

The front panel omits the Pride / Unity / Passion / Legacy mini-logo row (including the cup icon) for a cleaner cover. Middle and right panels keep their section icons.

## Regenerate

```bash
./brochure/generate_pdf.sh
```
